B1 · 单选题页签：Host 自持页签切换（点击 / ←→），扩展仅经 activeTab 回显接管。
  • 自动前进：仅多题布局、单选 list、未答→已答的 change → 跳至下一未答题（无则复核页）；回改已答题不前进。
  • 页签状态：题目页签已答 → status:"answered"；复核页全答 → answered，有缺 → attention。✓/⚠ 仅示意，实际由 Host 渲染。
  • 结构：tabs #questionnaire-tabs，页签 q0…qN-1 + review（label 复核）；所有页签 children 常驻树中，切页不丢值。

B3 · 复核页（全答完）：行摘要 + 补充内联预览 + 「修改」跳回（goto:<i>）。
  • 未作答行：header：未作答，tone:"warning"——状态词写在文案里，旧 Host 丢色仍可读。
  • 页签状态：全答 → answered（如本屏 ✓）；有缺 → attention（⚠，见 B1/B2）。
  • 补充预览：有选择的题目在摘要后追加「（补充：…）」，纯文本题直接显示文本。
  • 允许部分作答：提交不做完整性拦截，未答题不产生 answer。

交互规则 优化时的不变量

  1. 自动前进：多题布局下单选 list 的「未答→已答」change；跳下一未答题，无则复核页。多选勾选、自由输入、备注不触发；回改已答题不触发。
  2. 两段式取消：hasAnyWork（任一题已答）时首次取消仅布防；任意 change 解除；无工作直接关闭。
  3. 自由输入语义：有选择 → notes 补充；无选择 → custom 答案；复核页内联预览补充。
  4. 提交取值：Host 表单快照（event.values）优先，缺失字段回退扩展侧 shadow state。
  5. 状态词入文案：tone 可能被旧 Host 丢弃，「未作答」等状态必须保留在文本中。
  6. 回落：无 socket / 协议错误 / placement 被拒 → 静默回落 TUI / RPC（不在本稿范围）。
